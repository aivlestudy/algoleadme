## 스터디 규칙

1. 풀이는 `본인 아이디/문제 유형/` 폴더 안에 올립니다. (예: `RublerubitZ/BFS/숨바꼭질.py`)
2. `main`에 직접 푸시하지 않고, `차시-아이디` 브랜치를 만들어 PR로 올립니다. 문제 하나당 PR 하나씩 올립니다. (예: 첫 문제 `1-RublerubitZ`, 두 번째 문제 `2-RublerubitZ`)
3. PR 제목은 브랜치 이름과 같이 `차시-아이디`로 쓰고, 자동으로 채워지는 템플릿 항목을 모두 작성합니다.
4. PR을 만든 뒤 PR 번호를 확인해서 본인 폴더 `README.md` 표에 한 줄 추가하고, 같은 브랜치에 푸시합니다.
5. 코드 리뷰는 다 같이 통화로 모여서 진행하고, 리뷰가 끝난 PR은 작성자가 직접 Merge합니다.

자세한 방법은 [위키](https://github.com/aivlestudy/algoleadme/wiki)를 참고하세요.
