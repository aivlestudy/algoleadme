## 스터디 규칙

1. 풀이는 본인 아이디 폴더 안에 올립니다.
2. `main`에 직접 푸시하지 않고, 브랜치를 만들어 PR로 올립니다. (브랜치 이름 예: `아이디/1차시`)
3. PR 본문은 자동으로 채워지는 템플릿(문제 링크, 소요 시간, 접근 과정, 풀이 설명, 알게 된 것, 풀이 전체 코드)을 모두 작성합니다.
4. PR이 머지되면 본인 폴더의 `README.md` 표에 차시, 날짜, 문제 링크, PR 번호를 한 줄 추가합니다.
